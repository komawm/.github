# Koma

[Koma](https://github.com/komawm/koma) is a Wayland tiling compositor designed to support both a keyboard-driven desktop and explicit, isolated desktop automation interfaces.

The Rust compositor workspace contains protocol and layout models (`Dwindle` default, `Scrolling`, `Deck`, and `BSP`), sandboxed Phodopus Lua configuration with Hyprland-compatible default keybinds and typed appearance/shader/animation overrides, controller CLI (`komactl`), MCP adapter (`koma-mcp`), overview companion (`koma-overview`), and the canonical `flake.nix`. [Jiku](https://github.com/komawm/jiku) owns the companion desktop orchestration contracts and bundled skills, [koma-types](https://github.com/komawm/koma-types) owns LuaLS type definitions, [koma-docs](https://github.com/komawm/docs) owns canonical specifications and tri-lingual user manuals, [packaging](https://github.com/komawm/packaging) owns multi-distro packaging and guarded R2 CDN / GitHub Release delivery, and [website](https://github.com/komawm/website) serves the static portal at [komawm.org](https://komawm.org), the Jiku sub-site at [komawm.org/jiku/](https://komawm.org/jiku/), alongside the Cloudflare R2 CDN at [cdn.komawm.org](https://cdn.komawm.org). Existing code and specifications are under active `v0.0.x` incubation development; hardware behavior and security properties require independent validation.
