# Koma

[Koma](https://github.com/komawm/koma) is a Wayland tiling compositor designed to support both a keyboard-driven desktop and explicit, isolated desktop automation interfaces.

The Rust compositor workspace contains protocol and layout models, Lua integration, controller CLI, MCP adapter, and overview companion. [Jiku](https://github.com/komawm/jiku) owns the companion desktop agent and bundled skills, [koma-types](https://github.com/komawm/koma-types) owns Lua types, [koma-docs](https://github.com/komawm/docs) owns canonical specifications, and [packaging](https://github.com/komawm/packaging) owns distribution delivery. Existing code and specifications are under active development; hardware behavior and security properties require independent validation.
